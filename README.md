# Research No.87 — A Local Square Characterization of the Distance Cube Polynomial Identity in Induced Subgraphs of Hypercubes

Ryutaro Yonezu · v1.0 · 25 November 2026

**NOT HUMAN PEER REVIEWED · NOVELTY INCONCLUSIVE · REFERENCES PARTIAL**

This preprint establishes a necessary-and-sufficient local square condition for the distance cube polynomial identity in a fixed induced hypercube embedding. It addresses the induced, origin-containing scope of the first question after (5.1) in Mollard's arXiv:2410.19326v1, and explicitly extends the ambient-weight definitions to arbitrary vertex sets. No non-induced case or priority claim is made. Each component satisfying the criterion has a unique downward sink and a collapsible cubical complex; the latter results use established mathematical ideas.
